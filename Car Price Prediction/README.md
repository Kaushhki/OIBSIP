# Car Price Prediction using Machine Learning

## Project Overview
This project focuses on predicting the price of a car based on various features such as mileage, horsepower, engine capacity, and other relevant attributes. The goal is to build a machine learning model that can estimate car prices accurately using historical data.

## Objectives
- Analyze car dataset
- Perform data preprocessing and cleaning
- Identify key factors affecting car prices
- Train machine learning models for prediction
- Evaluate model performance

## Dataset Information
The dataset contains information about cars, including:
- Car name or brand
- Mileage
- Horsepower
- Engine size
- Fuel type
- Selling price

## Workflow
- Imported dataset using pandas
- Cleaned and preprocessed the data
- Handled missing values and irrelevant columns
- Performed exploratory data analysis
- Visualized relationships between features
- Selected important features
- Split dataset into training and testing sets
- Trained regression models
- Evaluated model performance

## Models Used
- Linear Regression
- (Add more if used: Random Forest Regressor, Decision Tree Regressor)

## Model Evaluation
The model was evaluated using:
- R-squared score
- Mean Squared Error

## Data Visualization
- Scatter plots to understand relationships between variables
- Heatmap to analyze correlation between features
- Distribution plots for feature analysis

## Results
The model was able to predict car prices with reasonable accuracy. Feature relationships such as mileage and engine size showed a strong influence on price.
