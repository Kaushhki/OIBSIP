# Sales Prediction using Machine Learning

## Project Overview
This project focuses on predicting product sales based on various factors such as advertising spend, target audience, and marketing platforms. The objective is to build a machine learning model that can estimate future sales and help in decision-making.

## Objectives
- Analyze sales dataset
- Understand the relationship between advertising and sales
- Perform data preprocessing and visualization
- Build a predictive machine learning model
- Evaluate model performance

## Dataset Information
The dataset contains:
- Advertising spend (TV, Radio, Newspaper, etc.)
- Sales data
- Other influencing factors

## Workflow
- Imported dataset using pandas
- Cleaned and preprocessed the data
- Performed exploratory data analysis
- Visualized relationships between advertising and sales
- Selected relevant features
- Split dataset into training and testing sets
- Trained regression model
- Evaluated model performance

## Model Used
- Linear Regression

## Model Evaluation
The model was evaluated using:
- R-squared score
- Mean Squared Error

## Data Visualization
- Scatter plots to analyze relationships between features and sales
- Line plots to observe trends
- Heatmap to understand correlation between variables

## Results
The model was able to predict sales based on advertising spend with good accuracy. It also highlighted how different marketing channels influence overall sales.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
